## Live session titles
Keep the current session title up to date: when a task starts, when the work changes stage, and when it ends.
- Write the title in the language of the conversation. About 6 words; a little longer only when needed, never hard to read.
- Name the task, not the tool. No quotes, no trailing period, no emoji.
- Do not create new sessions for this. Rename quietly, without announcing it.
